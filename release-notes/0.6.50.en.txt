Herdline 0.6.50 (experimental) — Gemini subagents in Chat, and Chat reports the pane size from the space under its header

- Chat: Gemini subagents show in Chat once each has finished, with its name, task, state (completed, failed or cancelled) and report, or its error. A subagent that is still running shows only when it ends. Code and unit tested only, not device-verified. Reading Gemini's subagent records was host runtime-checked by the developer with Gemini 0.68.0 and a test model provider.
- Chat: Stop now works for Gemini 0.68.0. It presses Esc only while Gemini's own working timer stands over its empty input box, with no shell holding focus and nothing waiting in its queue; the stop is not confirmed from Gemini's history. Send, attachments, steers, queueing and questions stay off for Gemini, and its agent card says why. Code and unit tested only, not device-verified. That Gemini 0.68.0 cancels a working turn on Esc was host runtime-checked by the developer, in stock Herdr 0.9.5 with a test model provider.
- Chat: under Chat, Herdline reports the pane size to Herdr once per visit, from the space under Chat's header, counted in the terminal's own font, and only once it knows the session is showing Chat, so a cold launch onto Chat no longer sends a Terminal size first. The keyboard and the composer moving in Chat still never resize the pane; Terminal is unchanged. Code and unit tested only, not device-verified.
- Chat: with OpenCode and Kilo, the pane's own server is checked again, still running and still in the pane, just before any request that changes something; otherwise nothing is sent. The pane report Herdline trusts must also name this pane. Code and unit tested only, not device-verified.
- Chat header: when the desktop is on another pane, the second line shows a monitor icon with the desktop's tab name, in place of "Desktop: …". The name is shortened to at least four characters with an ellipsis, or left out, and never cut to a fragment; the workspace name follows the same rule. The tab position, such as 2/5, keeps priority over the workspace name. Device-verified (QA, emulator, stock Herdr 0.9.5).
- Chat header: a small gap, never a separator dot, sets the monitor icon apart from what comes before it, and the second line keeps the height of one text line. Partly device-verified (QA, emulator, stock Herdr 0.9.5): the gap, and the header height with the tab position beside the icon, in English and Chinese at normal and large font sizes. The second line with only the icon left on it is code only, not unit tested.
- Terminal: key labels are drawn in the same line height they are measured with, so at the Compact density and large font sizes tall glyphs such as | and the g in PgUp or PgDn are no longer cut at the bottom. Device-verified (QA, emulator, stock Herdr 0.9.5).
- Accessibility: when the desktop is on another pane, TalkBack reads the session header with the tab you are reading and the desktop's tab, named as the visible header shows them; the visible note shows the desktop's tab name beside a monitor icon. Device-verified (QA, emulator, stock Herdr 0.9.5).
- Accessibility: the button that moves a custom key in Settings says it moves the key one place earlier, in English and Chinese, instead of "left". In Chinese, TalkBack joins the session header's sentences with a Chinese full stop. Device-verified (QA, emulator, stock Herdr 0.9.5).
- Chat: the composer names where it sends by the tab, as the header does, for every agent: in its To line, placeholder, hints and notices. When a pane in another tab has the same name, it says workspace › tab. Partly device-verified (QA, emulator, stock Herdr 0.9.5): the To line and the placeholder, with OMP and Claude Code. The hints, the notices and the same-name case are code and unit tested only.
- Terminal: extra keys whose cap shows only a symbol (arrows, Enter, Backspace) are read by TalkBack with a name in English or Chinese, and the custom-keys rows in Settings read the same name. Device-verified (QA, emulator, stock Herdr 0.9.5).
- Terminal: the extra keys are laid out in whole pixels, so the last key in a row is no longer cut at the screen edge. Device-verified (QA, emulator, stock Herdr 0.9.5).
- Chat: Send refusals and notices no longer name OMP when another agent is in the pane. They say "the agent" or describe what the agent must support instead, for example for attachments, steers and forms. Partly device-verified (QA, emulator, stock Herdr 0.9.5): with Claude Code, the "Can't read the input box" refusal, and the notice shown when the input box already has text, in English and Chinese. The attachment, steer and form wording is code and unit tested only.
- Tabs: when you choose a tab, pane or workspace, whether the desktop moves is decided from the Chat or Terminal modes as they are at that moment, including a mode you have just changed. Partly device-verified (QA, emulator, stock Herdr 0.9.5): with OMP. Known limit: if the connection stalls, a Terminal request already sent can still move the desktop after you pick another tab; the view you picked does not change.
- Chat: Send to Claude Code stays blocked with Herdr 0.9.5. Herdr 0.9.5 drops the true inverse cell style that Claude draws its input caret with; the hidden cursor position is still there, but Herdline needs that style to confirm Claude is at its prompt. A successful Send needs an upstream Herdr fix, and such a fix would still need testing. The input-box refusal messages no longer name a specific program. Partly device-verified (QA, emulator, stock Herdr 0.9.5): Send is refused with Claude Code, nothing is sent, and the refusal names no program. A successful Send is not verified.
- Chat: the "Opening Terminal" and "Couldn't open Terminal" messages name the tab as the header shows it. Device-verified (QA, emulator, stock Herdr 0.9.5).
- Chat: Terminal from Chat now also waits for the terminal picture to show the pane before it switches. It switches at once only when the desktop and its picture are both on that pane already. If the desktop is on the pane but the picture lags, it waits without asking the desktop to move. If the connection is not live, it says it couldn't open Terminal and offers Try again, without asking the desktop to move. Device-verified (QA, emulator, stock Herdr 0.9.5).
- Chat: Terminal from Chat now opens the pane you are reading. If the desktop is on another pane, the app moves it to that pane once; it shows "Opening Terminal for …" and stays in Chat until Terminal is showing that pane. If it can't, it says it couldn't open Terminal for that pane, keeps you reading it in Chat, and offers Try again. Device-verified (QA, emulator, stock Herdr 0.9.5).
- Tabs: the view button in the Tabs header now cycles List, Two columns and Workspace rails. Under the host, a second line shows the tab and workspace counts; a long host name is shortened first, before the counts. Partly device-verified (QA, emulator, stock Herdr 0.9.5): the view button's cycle.
- Chat: the pane you select stays in Chat and shows its own loading, history or read-error state. A page read successfully with no entries shows as empty. A history that is not written yet stays a read error with Retry, and recovers through the usual polling. An agent that refuses shows its refusal text with Open Terminal. Chat no longer falls back to Terminal on its own; Terminal opens only when you choose it. The old notice saying Chat can't read this agent, so this tab shows Terminal, is removed. Partly device-verified (QA, emulator, stock Herdr 0.9.5), with OMP and Claude Code: a selected pane whose history is not written yet stays in Chat with the read error, Retry and Open Terminal, then shows its history through polling. The empty page and the refusal state are code and unit tested only. That this fixes the reported incident is inferred, not proven on a device.
- Agents: the Agents screen uses a compact header, without the large empty space above the title. Code and unit tested only, not device-verified.
- Chat: a steer typed into a working OMP pane says it waits in OMP and is marked delivered once OMP's history holds it. Code and unit tested only, not device-verified.
- Tabs: the Tabs sheet has one header in List, Two columns and Workspace rails, with New tab always on its own row at the right, above Search. Code and unit tested only, not device-verified.
- Chat: dragging the Chat list by hand hides the keyboard once; the draft is kept. Code and unit tested only, not device-verified.
- Tabs: Settings › Layout › Tabs view offers Workspace rails: workspaces scroll down, and each workspace's tabs sit in one row that scrolls sideways. List stays the default. Code and unit tested only, not device-verified.

Device-verified means checked by QA on an Android emulator with stock Herdr 0.9.5, using OMP and Claude Code with a test model provider, on this build or an earlier one, carried forward only where the code path is unchanged. No line claims more on a device than QA proved. Lines not marked device-verified are code and unit tested, except the parts marked code only, which are not unit tested.

This is an experimental build, and support for agent harnesses is not complete.

Known limits:
- The composer's same-name case (workspace › tab) was not run on a device.
- Nothing is verified on a phone, including a stock Samsung phone.
- A desktop focus request already sent can still land after you pick another tab; the view you picked stays.
- This release makes no promise of automatic reconnect.
