Herdline 0.6.68 (experimental) — audit repairs

- Removed Output focus from the session and composer menus. Terminal no longer has the side composer required by that mode, so the old switch could never apply. Its screen state, output window and strip are removed; normal terminal anchoring, selection and receipt viewport checks remain.
- Disabled Insert without Enter now explains the gate that holds it: delivery in progress, an unconfirmed delivery, withdrawing, changed or offline target, empty draft, files still uploading or not ready, a check not yet available, the desktop on another tab, or the native pane refusal. Enabled Insert keeps its ordinary help. Delivery safety checks are unchanged. English and Chinese.
- Notification text and actions refresh when the app or system language changes, without restarting the connection. The app refreshes channel names and retained agent notes even with no connection service; the service refreshes the live, attached and lost-link cards. Privacy, notification identities, pins and promotion rules are unchanged.
- The bell setting is now labelled Touch feedback on bell, with its limits shown. Feedback uses the foreground session's attached root view in Chat and Terminal, reads the current setting for each bell, and respects Android touch feedback settings. It requires haptic hardware; no background vibration or new vibration permission is added.
- Attach and Stop support now belong to each Harness route row. The agent card's corresponding claims must agree with those routes; display claims never enable controls. No new agent capability is claimed.
- Integrated the four dependency update groups locally: AGP 9.5.1, Gradle 9.8.2, russh 0.65.1, interprocess 2.4.8, rustix 1.1.6, tokio 1.54.1, unicode-width 0.2.3 and pinned GitHub Actions updates.
- Release publication now depends on a fresh reusable CI invocation at the same source commit, including bounded existing rendered header, pin-sheet and terminal keyboard checks. Release verification no longer shares a cancellation group with ordinary push CI. The accumulated Rust formatting failures were corrected.

Developer verification: 131 JVM tests across 21 selected owners passed; 23 native viewport tests and 46 changed native-owner tests passed; cargo test --workspace and cargo clippy --workspace --all-targets -D warnings passed; QA APK and instrumentation APK built with the updated native dependencies; actionlint and cargo fmt --check passed. This does not claim that the hosted GitHub workflow ran.

Limits: targetSdk remains 36; Android 37 local-network permission handling belongs to a future targetSdk 37 migration, not a new permission request now. The below-API-33 locale path is source/contract reviewed, not device-verified. No physical phone, Samsung Now Bar placement or physical vibration is claimed. QA results refer to the exact separately recorded candidate APK and do not imply full regression coverage.
