Herdline 0.6.20 — Chat comes back after a refusal ends

When Chat couldn't read an agent's history for a reason that lasts (for example, two sessions for one pane) and that reason later went away, tapping Chat could keep repeating the old message. Only restarting the app helped.

Now each Chat tap reads the pane again. If Chat still can't read it, you see why. If it can, Chat opens.
