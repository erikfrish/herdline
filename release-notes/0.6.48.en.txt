Herdline 0.6.48 (experimental) — the header's desktop icon gets a gap instead of a dot, and the header keeps its height

- Chat header: when the desktop is on another pane, the second line shows a monitor icon with the desktop's tab name, in place of "Desktop: …". A small gap sets the icon apart from what comes before it, never a separator dot. The name is shortened to at least four characters with an ellipsis, or left out, and never cut to a fragment; the workspace name follows the same rule. The tab position, such as 2/5, keeps priority over the workspace name. Code and unit tested only, not device-verified. The second line keeps one text line of height even when only the icon is left; this part is code only, not unit tested or device-verified.
- Accessibility: the button that moves a custom key in Settings now says it moves the key one place earlier, in English and Chinese, instead of "left". In Chinese, TalkBack joins the session header's sentences with a Chinese full stop. Code only, not unit tested or device-verified.
- Terminal: key labels are drawn in the same line height they are measured with, so at the Compact density and large font sizes tall glyphs such as | and the g in PgUp or PgDn are no longer cut at the bottom. Code and unit tested only, not device-verified.
- Accessibility: when the desktop is on another pane, TalkBack reads the session header with the tab you are reading and the desktop's tab, named as the visible header shows them; the visible note shows the desktop's tab name beside a monitor icon. Code and unit tested only, not device-verified.
- Chat: the composer names where it sends by the tab, as the header does, for every agent: in its To line, placeholder, hints and notices. When a pane in another tab has the same name, it says workspace › tab. Code and unit tested only, not device-verified.
- Terminal: extra keys whose cap shows only a symbol (arrows, Enter, Backspace) are read by TalkBack with a name in English or Chinese, and the custom-keys rows in Settings read the same name. Code and unit tested only, not device-verified.
- Terminal: the extra keys are laid out in whole pixels, so the last key in a row is no longer cut at the screen edge. Code and unit tested only, not device-verified.
- Chat: Send refusals and notices no longer name OMP when another agent is in the pane. They say "the agent" or describe what the agent must support instead, for example for attachments, steers and forms. Code and unit tested only, not device-verified.
- Tabs: when you choose a tab, pane or workspace, whether the desktop moves is decided from the Chat or Terminal modes as they are at that moment, including a mode you have just changed. Code and unit tested only, not device-verified.
- Chat: Send to Claude Code stays blocked with Herdr 0.9.5. Herdr 0.9.5 does not pass Claude's input caret to apps, so Herdline cannot confirm Claude is at its prompt. This needs a Herdr update. Herdline's own reading of Claude's mode line and caret is in place but cannot take effect until then. The input-box refusal messages no longer name a specific program. Code and unit tested only, not device-verified.
- Chat: the "Opening Terminal" and "Couldn't open Terminal" messages name the tab as the header shows it. Code and unit tested only, not device-verified.
- Chat: Terminal from Chat now also waits for the terminal picture to show the pane before it switches. It switches at once only when the desktop and its picture are both on that pane already. If the desktop is on the pane but the picture lags, it waits without asking the desktop to move. If the connection is not live, it says it couldn't open Terminal and offers Try again, without asking the desktop to move. Code and unit tested only, not device-verified.
- Chat: Terminal from Chat now opens the pane you are reading. If the desktop is on another pane, the app moves it to that pane once; it shows "Opening Terminal for …" and stays in Chat until Terminal is showing that pane. If it can't, it says it couldn't open Terminal for that pane, keeps you reading it in Chat, and offers Try again. Code and unit tested only, not device-verified.
- Tabs: the view button in the Tabs header now cycles List, Two columns and Workspace rails. Under the host, a second line shows the tab and workspace counts; a long host name is shortened first, before the counts. Code and unit tested only, not device-verified.
- Chat: the pane you select stays in Chat and shows its own loading, history or read-error state. A page read successfully with no entries shows as empty. A history that is not written yet stays a read error with Retry, and recovers through the usual polling. An agent that refuses shows its refusal text with Open Terminal. Chat no longer falls back to Terminal on its own; Terminal opens only when you choose it. The old notice saying Chat can't read this agent, so this tab shows Terminal, is removed. Code and unit tested only, not device-verified; nothing here has passed a run on a device yet. That this fixes the reported incident is inferred, not proven on a device.
- Agents: the Agents screen uses a compact header, without the large empty space above the title. Code and unit tested, not device-verified.
- Chat: a steer typed into a working OMP pane says it waits in OMP and is marked delivered once OMP's history holds it. Code and unit tested, not device-verified.
- Tabs: the Tabs sheet has one header in List, Two columns and Workspace rails, with New tab always on its own row at the right, above Search. Code and unit tested, not device-verified.
- Chat: dragging the Chat list by hand hides the keyboard once; the draft is kept. Code and unit tested, not device-verified.
- Tabs: Settings › Layout › Tabs view offers Workspace rails: workspaces scroll down, and each workspace's tabs sit in one row that scrolls sideways. List stays the default. Code and unit tested, not device-verified.

Nothing above is verified by QA or on a device yet.
