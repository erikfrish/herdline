Herdline 0.6.49（实验版）— Gemini 可以停止，聊天中的窗格尺寸每次进入后稳定上报一次，OpenCode 和 Kilo 在做出更改前再次检查本窗格的服务器

- 聊天：现在可以停止 Gemini 0.68.0。仅当 Gemini 自己的工作计时行位于其空输入框上方、没有获得焦点的 shell 且队列中没有等待内容时才按 Esc；停止不通过 Gemini 的历史记录确认。Gemini 的发送、附件、插话、排队和问题仍保持关闭，其智能体卡片说明原因。仅经代码和单元测试，未在设备上验证。Gemini 0.68.0 在工作中按 Esc 会取消当前回合，这一点已由开发者在主机上运行检查（原版 Herdr 0.9.5，测试用模型服务）。
- 聊天：在聊天中，Herdline 现在每次进入时按聊天稳定后的布局向 Herdr 上报一次窗格尺寸，因此冷启动时或从终端（其额外按键和键盘）带来的尺寸不再留在聊天中。聊天中键盘和输入框的移动仍不会改变窗格尺寸；终端不变。仅经代码和单元测试，未在设备上验证。
- 聊天：使用 OpenCode 和 Kilo 时，在任何会做出更改的请求之前，会再次检查本窗格自己的服务器仍在运行且仍在该窗格中；否则不发送任何内容。Herdline 信任的窗格进程报告也必须指向本窗格。仅经代码和单元测试，未在设备上验证。
- 聊天标题栏：当桌面位于另一个窗格时，第二行显示显示器图标和桌面所在标签页的名称，取代原来的“桌面：…”。名称至少保留四个字符并加省略号，或者整个省略，绝不会截成残缺片段；工作区名称遵循相同规则。标签页位置（如 2/5）优先于工作区名称显示。已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）。
- 聊天标题栏：显示器图标与前面的内容之间以小间距分隔，绝不使用分隔点；第二行保持一行文字的高度。部分已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）：间距，以及图标旁显示标签页位置时的标题栏高度，中文和英文，常规和大号字体。第二行只剩图标时的情况仅经代码检查，未经单元测试。
- 终端：按键标签的绘制行高与测量时一致，因此在“紧凑”密度和较大字号下，| 以及 PgUp、PgDn 中的 g 等较高字形底部不再被截断。已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）。
- 无障碍：当桌面位于另一个窗格时，TalkBack 读出会话标题栏中你正在阅读的标签页和桌面所在的标签页，名称与可见的标题栏一致；可见的提示在显示器图标旁显示桌面所在标签页的名称。已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）。
- 无障碍：设置中移动自定义按键的按钮现在说明将按键前移一位（中文和英文），不再说“向左”。中文下，TalkBack 用中文句号连接会话标题栏中的各句。已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）。
- 聊天：输入框按标签页指明发送目标，与标题栏一致，适用于所有智能体：包括“发送至”行、占位文字、提示和通知。当另一个标签页中的窗格同名时，显示为“工作区 › 标签页”。部分已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）：“发送至”行和占位文字，使用 OMP 和 Claude Code。提示、通知和同名情况仅经代码和单元测试。
- 终端：键帽上只显示符号的额外按键（方向键、回车、退格），TalkBack 会以中文或英文名称读出；设置中的自定义按键行也读出相同名称。已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）。
- 终端：额外按键按整像素排布，行末最后一个按键不再在屏幕边缘被截断。已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）。
- 聊天：当窗格中是其他智能体时，发送被拒原因和提示不再点名 OMP，而是写“智能体”，或说明智能体需要支持什么，例如附件、插话（steer）和表单。部分已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）：使用 Claude Code 时的“无法读取输入框”拒绝提示，以及输入框中已有文字时的提示（中文和英文）。附件、插话和表单相关的措辞仅经代码和单元测试。
- 标签页：选择标签页、窗格或工作区时，是否移动桌面按当下的聊天或终端模式决定，包括刚刚切换的模式。部分已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）：使用 OMP。已知限制：如果连接停滞，已经发出的打开终端请求在你选择另一个标签页后仍可能移动桌面；你选择的视图不会改变。
- 聊天：在 Herdr 0.9.5 下，向 Claude Code 发送仍被阻止。Herdr 0.9.5 会丢弃 Claude 绘制输入光标所用的真正反色单元格样式；隐藏的光标位置仍然存在，但 Herdline 需要该样式才能确认 Claude 处于输入提示处。要成功发送需要 Herdr 上游修复，且这样的修复仍需测试。输入框相关的拒绝提示不再点名具体程序。部分已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）：使用 Claude Code 时发送被拒绝，不会发送任何内容，拒绝提示未点名具体程序。成功发送未经验证。
- 聊天：“正在打开终端”和“无法打开终端”的提示按标题栏显示的名称指明标签页。已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）。
- 聊天：从聊天打开终端时，现在还会等终端画面显示该窗格后再切换。只有当桌面和画面都已在该窗格上时才立即切换。如果桌面已在该窗格上而画面滞后，则等待，不要求桌面移动。如果连接未在线，则提示无法打开终端并提供“重试”，不要求桌面移动。已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）。
- 聊天：从聊天打开终端现在会打开你正在阅读的窗格。如果桌面在另一个窗格上，应用会把它移到该窗格一次；显示“正在打开终端……”，并留在聊天中，直到终端显示该窗格。如果无法打开，会提示无法为该窗格打开终端，让你继续在聊天中阅读，并提供“重试”。已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）。
- 标签页：标签页标题栏中的视图按钮现在在“列表”、“两列”和“工作区横排”之间循环。主机名下方第二行显示标签页和工作区数量；主机名过长时先缩短主机名，再缩短数量。部分已在设备上验证（QA，模拟器，原版 Herdr 0.9.5）：视图按钮的循环。
- 聊天：你选中的窗格会停留在聊天中，并显示它自己的加载、历史或读取错误状态。成功读取但没有条目的页面显示为空。尚未写入的历史保持为带“重试”的读取错误，并通过常规轮询恢复。拒绝的智能体会显示其拒绝文字和“打开终端”。聊天不再自行回退到终端；只有在你选择时才打开终端。旧的“聊天无法读取此智能体，因此此标签页显示终端”提示已移除。部分已在设备上验证（QA，模拟器，原版 Herdr 0.9.5），使用 OMP 和 Claude Code：历史尚未写入的选中窗格停留在聊天中，显示读取错误、“重试”和“打开终端”，随后通过轮询显示其历史。空页面和拒绝状态仅经代码和单元测试。此修复解决了所报告的问题这一点是推断，尚未在设备上证实。
- 智能体：智能体页面使用紧凑的标题栏，标题上方不再有大块空白。仅经代码和单元测试，未在设备上验证。
- 聊天：在正在工作的 OMP 窗格中输入的插话会说明它在 OMP 中等待，并在 OMP 的历史记录收到后标记为已送达。仅经代码和单元测试，未在设备上验证。
- 标签页：标签页面板在“列表”、“两列”和“工作区横排”中只有一个标题栏，“新建标签页”始终单独一行靠右，位于搜索上方。仅经代码和单元测试，未在设备上验证。
- 聊天：手动拖动聊天列表时会收起一次键盘；草稿保留。仅经代码和单元测试，未在设备上验证。
- 标签页：设置 › 布局 › 标签页视图提供“工作区横排”：工作区纵向滚动，每个工作区的标签页排成一行横向滚动。默认仍为“列表”。仅经代码和单元测试，未在设备上验证。

“已在设备上验证”指 QA 在 0.6.48（构建 10083）上于 Android 模拟器中使用原版 Herdr 0.9.5 检查，使用 OMP 和 Claude Code 以及测试用模型服务。未标注已在设备上验证的条目经代码和单元测试，但注明仅经代码检查的部分未经单元测试。

这是实验版本，对各智能体的支持尚不完整。

已知限制：
- 输入框的同名情况（工作区 › 标签页）未在设备上运行。
- 尚未在手机上验证任何内容，包括原版系统的三星手机。
- 已经发出的桌面焦点请求在你选择另一个标签页后仍可能生效；你选择的视图保持不变。
- 本版本不承诺自动重连。
